# Handoff Eval Agent Limitations

- This is a polished portfolio MVP, not a fully deployed production system.
- The public demo uses seeded/mock data.
- Claude integration is architected and documented, but the demo uses safe local fallbacks unless an API key is added.
- Static analysis and eval fixtures cannot prove runtime behavior by themselves.
- Real nonprofit, youth, or client data would require stronger authentication, privacy review, and access controls before use.
