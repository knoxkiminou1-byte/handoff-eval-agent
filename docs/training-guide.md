# Handoff Eval Agent Training Guide

## Audience

Nontechnical staff, mentors, or program operators who need to use or inherit the system.

## Training Flow

1. Explain the workflow problem the tool supports.
2. Walk through the demo with seeded data.
3. Show where AI helps and where deterministic code handles facts.
4. Review the human approval gate.
5. Practice one eval case together.
6. Discuss limitations and escalation paths.

## Safe Use Rule

AI output should accelerate review, not replace judgment. Staff should verify important facts before exporting or sending any report, asset, or handoff package.
